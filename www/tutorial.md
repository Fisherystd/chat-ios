# 人设聊天室（本机版）· 使用教程

> ## 本机版说明（重要，先读这里）
>
> 本页面是「本机版」：**无需登录、无需服务器账户**，打开即可使用，所有数据（人设、聊天、设置）只保存在**你手机/电脑的浏览器本地**。
>
> - **数据仅存本机**：清除 Safari 网站数据、卸载或重置浏览器会丢失全部内容，请**定期导出备份**（「设置」→「数据备份 / 恢复」→ 导出 JSON 文件保存）。
> - **API Key**：本机版直连 DeepSeek 官方接口，请先在「设置」里填写**你自己的 DeepSeek API Key**（保存在本机浏览器，不经过任何服务器）。
> - **离线限制**：加载过一次后外壳可离线打开，但**离线时只能查看**人设与聊天记录，不能对话（对话需要联网调用 DeepSeek）。
> - **本机版不支持**：按下载链接抓取导入（请改用「粘贴对话内容」导入）、账号注册/管理员功能/多设备同步等服务器专属能力。
>
> ## iPhone 安装到主屏幕
>
> 1. 用 Safari 打开本页面；
> 2. 点击底部**分享按钮**（方框加向上箭头）；
> 3. 选择「**添加到主屏幕**」→ 点「添加」；
> 4. 主屏幕会出现「人设聊天室」图标，像 App 一样打开（全屏、无地址栏）。

## 一、快速开始

1. 用 Safari 打开本页面，并按上面步骤「添加到主屏幕」。
2. 先到「设置」填写自己的 DeepSeek API Key（见第二节）。
3. 到「人设」创建角色设定 → 到「聊天」新建聊天选择人设 → 开始对话。

## 二、配置 DeepSeek API Key

每位用户使用**自己的** DeepSeek API Key，额度独立。本机版的 Key 只保存在你的浏览器本地。

1. 点击顶部「设置」。
2. 在「DeepSeek API Key」输入框中粘贴你的 Key（`sk-` 开头）。
3. 点击「保存 Key」；可点击「测试 Key」验证是否可用。
4. 已配置后输入框留空保存 = 不修改；也可「清除已存 Key」。
5. 可在「默认模型」中选择 `deepseek-chat` 或 `deepseek-reasoner`。

> 记忆、历史压缩、状态更新、文档分析等功能都需要先配置有效的 API Key。

## 三、创建人设（含人物属性与状态系统）

点击顶部「人设」→「＋ 新建人设」。

- **名称**：角色名字（1-50 字）。
- **角色头像**（可选）：每个角色可上传自己的头像（`png` / `jpg` / `jpeg` 图片，≤2MB）；本机版会自动压缩头像（最长边 ≤512px）以节省本机存储。新建人设请先保存后再上传头像。
- **人设内容**：描述角色的身份、性格、说话风格、背景故事等。
- **从文件导入**：可以把已有的人设文件读入正文，支持 `txt`、`md`、`markdown`、`json`、`html`、`htm`、`rtf`、`docx` 格式（Word 文档也能读取）；导入后可在正文中继续修改。
- **人物属性**（可选）：自定义属性名与属性值（如 `年龄` / `25`、`职业` / `咖啡师`），保存后自动写入人设文件，聊天时作为设定生效。
- **状态系统**（可选）：
  - 打开「启用状态系统」开关；
  - 添加状态属性并设置**初始值**（如 `好感度` / `0`、`心情` / `平静`）；
  - 保存后，聊天界面会显示「角色状态」面板，并且每轮回复前模型都会在**后台（用户不可见）**判断这段对话对状态的影响并更新数值。
- 保存后可在列表中点「下载」把该人设导出为 txt 文件备份。

## 四、开始聊天

1. 点击顶部「聊天」→ 左侧「＋ 新建」→ 选择人设 → 开始对话（弹窗中可顺便填写「我的身份」，见下文第 7 条）。
2. **上下文记忆**：同一个聊天内会自动携带最近 60 条历史消息，模型记得前面的对话；新建聊天则是全新上下文。
3. 回复为流式生成，支持 Markdown 显示；生成中可点「停止」中断。若回复中出现中文以外的文字（如英文、日文等），模型会在其后用 `{}` 括起对应的简体中文翻译，方便阅读。
4. 聊天顶部操作：
   - **压缩历史**：把较早的对话压缩成摘要（只保留最近 20 条原文），释放上下文空间；点击前会确认，压缩后不可撤销。
   - **导出**：可导出 Markdown / 纯文本 / JSON。
   - **删除聊天**：会话列表对应项右侧「×」。
5. **上传文档**（输入框旁按钮，仅支持 .txt）：
   - 上传后文档会交给大模型，模型可以读取并参考它；
   - 模型会自动判断文档是否含人设相关内容，若包含会弹出建议框：
     - 「加入人设」：把相关段落追加到当前聊天使用的人设里；
     - 「忽略」：仅作为参考文档保留；
     - 勾选「以后不再提醒」：之后上传不再弹出该建议（文档仍会交给模型）。
6. **角色状态面板**（人设启用了状态系统时）：显示该聊天中角色当前的好感度/心情等状态值，随对话自动更新。
7. **我的身份（自我人设）**：可以为自己（对话者）设定身份，聊天时会以该身份与角色互动。
   - 点击聊天头部「**我的身份**」按钮编辑（例如：你是谁、与角色是什么关系、希望角色如何称呼你）；
   - 勾选「**保存为默认人设（以后新建聊天自动使用）**」后，新建聊天会自动带上该身份；
   - 新建聊天弹窗中也可以直接填写「我的身份」并勾选保存为默认；
   - 聊天头部会显示「已设置我的身份」标识。
8. **对话设置（聊天模式 / 故事模式 / 小说模式 + 长短与推理强度）**：点击聊天头部「**对话设置**」按钮：
   - **聊天模式**：角色只进行对话（默认）；
   - **故事模式**：角色回复会附带神态、动作、心理与场景描写，并承接你的角色动作与故事线，适合沉浸式剧情；
   - **小说模式**：基于人设设定与已有背景，以小说体裁创作/续写长文（篇幅尽量长、情节完整、描写丰富），适合让角色"写小说"；
   - **回话长短**（聊天模式下）：可设定最短/最长回话字数（默认 20-500 字）；
   - **故事长短**（故事模式下）：可设定最短/最长故事字数（默认 300-800 字）；
   - **环境描写**（故事模式下）：可开关「要求包含环境与人物周围描写」，并设定描写字数（默认 150 字，0-2000）；
   - **小说长短**（小说模式下）：可设定最短/最长小说字数（默认 1200-3000 字，篇幅越大生成越慢、消耗越多）；
   - **推理强度**：可设置 关闭 / 低 / 中 / 高（默认中），控制模型思考程度；越高越"深思熟虑"，但回复更慢、更费额度（高强度可配合「设置 → 默认模型 → deepseek-reasoner」使用）；
   - 聊天标题旁会显示当前模式（聊天模式 / 故事模式 / 小说模式）。

## 五、导入 DeepSeek 聊天记录生成人设

本机版**不支持按下载链接抓取**（浏览器跨域限制），请改为**粘贴对话内容**：

1. 在 DeepSeek 移动端打开聊天记录导出/分享，复制其中的对话文本（【用户】/【助手】内容）。
2. 点击顶部「导入」。
3. 步骤 1：把对话文本**粘贴**到输入框，点击「提取人设」。
4. 步骤 3：核对并修改提取出的人设文本（可编辑），填写名称后「保存人设」。
5. 提示：已配置 API Key 时使用 AI 提取，效果更好；未配置时仅做启发式提取。

## 六、关于账号与管理功能

本机版**没有账号系统**：无需注册、无需登录，也没有管理员/多用户/在线状态等服务器功能。你创建的人设与聊天只属于本机浏览器。

## 七、在 iPhone 上安装（手机端）

本应用已适配 iPhone，可把网页「添加到主屏幕」，以独立窗口像 App 一样使用（无需 App Store）：

1. 用 iPhone 的 **Safari** 浏览器打开本网站（必须是 Safari；微信内置浏览器不支持安装）。
2. 点击 Safari 底部的「**分享**」按钮（方框带向上箭头）。
3. 在弹出的菜单中选择「**添加到主屏幕**」，确认名称后点「**添加**」。
4. 回到主屏幕，即可看到「人设聊天室」图标，点开就是全屏应用（无地址栏）。

说明：
- 应用功能与浏览器访问一致，**需要联网**且服务器在线；
- 首次打开若弹出「安装到主屏幕」提示条，点 × 可关闭（不再提示）；
- 如需上架 App Store（App 商店分发），需要 Mac + Xcode + Apple 开发者账号，不在当前方案内。

## 八、常见问题

- **提示「未配置 API Key」**：到「设置」填写自己的 Key 后再试。
- **压缩/状态/文档分析没有反应**：确认 Key 有效、账户额度充足；网络异常时稍后重试。
- **修改配置后页面没变化**：按 `Ctrl + F5` 强制刷新浏览器缓存。
- **提示"该账户已在另一处登录，当前会话已失效"并退出登录**：同一账户同一时间只允许一处登录，在别处登录后旧会话会自动下线；重新登录即可继续使用（请勿与他人共用账户）。
- **电脑与手机**：同一网址访问，界面会自动适配；iPhone 可按第七节「添加到主屏幕」安装为独立应用。
- **数据安全**：人设与聊天记录保存在服务器上的个人账户目录中，可随时导出备份；不同账户的数据互相隔离、不可见。
